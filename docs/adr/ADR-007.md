## ADR-007: Daten-Pipeline
**Status:** Gebilligt  
**Datum:** 2026-10-18

### Kontext
Optimale Methode für Datenabfrage: WebSocket + Caching

### Entscheidung
**Hybrid-Ansatz:**
1. **Historische Daten:** REST-API `get_historical_klines()` beim ersten Laden
2. **Echtzeit-Updates:** WebSocket-Connection für laufende Updates
3. **Cache:** `deque(maxlen=500)` pro Symbol/Timeframe
4. **Indikatorwerte:** Bereits von Binance berechnet (aus Kline-Daten extrahieren)

### Konsequenzen
+ Balance zwischen Latenz und API-Nutzung
+ Funktioniert zuverlässig im Testnet
+ Erweiterbar für andere Timeframes
- WebSocket-Connection muss überwacht werden
