## ADR-002: MCP-Server Architektur
**Status:** Gebilligt  
**Datum:** 2026-10-18

### Kontext
Der Benutzer möchte ein Programm, das:
1. Von Claude Code via MCP angesprochen werden kann
2. Als eigenständige Web-API funktioniert
3. Nicht an Claude Code gebunden ist

### Entscheidung
**Dual-Architektur:**
- **MCP Server** für Claude Code Integration (Tools-Definitionen)
- **REST-API** für direkte Web-Zugriffe (Flask/Express)
- **Gemeinsamer Backend-Code** für beide Interfaces

### Konsequenzen
+ Maximale Flexibilität: Claude Code ODER Web-API
+ Ein Codebasiss, zwei Schnittstellen
+ Future-proof für weitere Integrationen
- Mehr initiale Code-Komplexität

### Alternativen verworfen
- A) Nur MCP: Zu abhängig von Claude Code
- B) Nur REST-API: Verpasst MCP-Integration Möglichkeiten
