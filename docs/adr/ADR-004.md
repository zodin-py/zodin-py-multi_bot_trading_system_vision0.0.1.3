## ADR-004: Stop-Loss / Take-Profit Logik
**Status:** Gebilligt  
**Datum:** 2026-10-18

### Kontext
TP soll doppelt so groß sein wie SL (2:1 Risk-Reward-Ratio). SL sollte dynamisch basierend auf Support/Resistance berechnet werden.

### Entscheidung
**Dynamisches SL/TP-System:**
1. **Primär:** SL basierend auf Support/Resistance-Leveln (wenn sichtbar)
2. **Fallback:** Statisches SL basierend auf ATR oder % (z.B. 1%)
3. **TP berechnen:** TP = Entry + (Entry - SL) × 2 für Long (bzw. umgekehrt für Short)

### Konsequenzen
+ Intelligentere Trade-Auswahl basierend auf Marktstruktur
+ 2:1 Risk-Reward gewährleistet positive Erwartung im Durchschnitt
- Komplexere Berechnungslogik

### Formel
```python
# Long
SL = nearest_support_level
TP = entry_price + (entry_price - SL) * 2

# Short
SL = nearest_resistance_level
TP = entry_price - (SL - entry_price) * 2
```
