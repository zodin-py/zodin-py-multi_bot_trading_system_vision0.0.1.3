## ADR-005: Risk-Management und Verlustlimit
**Status:** Gebilligt  
**Datum:** 2026-10-18

### Kontext
System muss automatisch stoppen, wenn ein bestimmtes Verlustlimit erreicht ist. Nutzer setzt Betrag frei (z.B. 10€).

### Entscheidung
**Maximales Verlustlimit pro Tag:**
- Konfigurierbare Grenze (Default: 10€ Verlust)
- **Trading-Loop beendet sofort** wenn Grenze erreicht
- Reset täglich oder manuell

### Konsequenzen
+ Schützt vor übermäßigen Verlusten
+ Erzwungene Pause zur Reflexion
+ Psychologische Disziplin
- Muss manuell resettet werden nach Limit
