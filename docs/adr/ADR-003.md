## ADR-003: Technische Stack-Wahl
**Status:** Gebilligt  
**Datum:** 2026-10-18

### Kontext
MCP-Server muss Python oder TypeScript sein. Python hat Vorteile durch bestehenden Code und Bibliotheken.

### Entscheidung
**Python mit folgenden Bibliotheken:**
- `binance-connector` oder `python-binance` für API-Zugriff
- `pandas` und `numpy` für Datenverarbeitung
- `websockets` für Echtzeit-Daten
- `Flask` oder `FastAPI` für REST-API
- `mcp` Python Library für MCP-Integration

### Konsequenzen
+ Konsistenz mit bestehendem Projekt
+ Reife Trading-Bibliotheken
+ Große Community und Dokumentation
- Performance limitiert gegenüber Rust/Go (inakzeptabel für diese Anwendung)
