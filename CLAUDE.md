# Multi-Bot Trading System

## Agent skills

### Issue tracker

Issues and specs are tracked locally as markdown files under `.scratch/<feature>/`. No GitHub CLI required. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles mapped to identical label strings: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout. `GLOSSARY.md` at repo root, ADRs in `docs/adr/`. See `docs/agents/domain.md`.
